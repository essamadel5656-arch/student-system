# 🎓 Student Management System (Laravel 12)

This is a professional web application built with **Laravel 12** to manage students, subjects, and academic records.

## 🚀 Features (Work in Progress)
- **Student Management:** Add, edit, and delete student profiles.
- **Subject Tracking:** Manage academic subjects and courses.
- **Modern UI:** Built using Laravel Blade and styled for a clean user experience.
- **Database Architecture:** Optimized SQL schema for educational data.

## 🛠️ Tech Stack
- **Framework:** Laravel 12
- **Language:** PHP
- **Database:** MySQL
- **Frontend:** Blade Templates & CSS

## 📌 Status
This project is currently under active development. I am focusing on building a robust backend and clean database migrations.
